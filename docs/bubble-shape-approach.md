## 1. いま特に問題になっている形

| トーン | ツール版の傾向 | 理想に近い感じ |
|--------|----------------|----------------|
| **thought（雲）** | 大きすぎ・輪郭がぼんやり／sin バンプで蜘蛛・ウニっぽい | **コンパクト**、輪郭が**柔らかく**自然なわた雲 |
| **shout（ギザギザ）** | トゲが多すぎ、「爆発マーク」寄り | **角張った楕円 ＋ 適度なトゲ**（控えめ） |

通常楕円＋短い尻尾は、配置・サイズが直れば相対的にマシになりやすい。  
形状の本丸は **thought / shout**。

---

## 2. 二つの方式の比較

### A. 素材を集めて選ぶ

**メリット**

- 実マンガ由来なら一発で「漫画らしい」質感
- 実装が比較的シンプル（マッチング or ルール選択）
- トーンごとに複数原型でバリエーション

**デメリット**

- 素材の量・質に依存
- 尻尾の角度・接続の後付けが難しい
- 新トーン・中間感情で素材不足
- **著作権**（切り抜き素材を同梱・配布する場合）

### B. 傾向分析 → パラメータ生成

**メリット**

- 尻尾の向き・長さ・接続を顔位置から制御しやすい
- 「少し強めの叫び」など連続調整が可能
- 素材の著作権を気にしにくい

**デメリット**

- いいパラメータ探しに時間がかかる
- 初期は不自然な形が出やすい
- 手描き感・インク揺らぎの再現が難しい

---

## 3. 推奨: ハイブリッド（採用方針）

> **ベース形状は素材（または手描き原型）から選ぶ ＋ 変形・しっぽはパラメータで制御**

### 流れ（pipeline 上）

```text
tone 解決
    → shape template 選択（tone + 文字量 + seed）
    → affine 変形（scale / アスペクト / 回転）
    → 配置 bbox にフィット
    → しっぽ（tone による: shout は基本なし / normal は短く / thought は丸連なり）
    → ラスタ描画
```

今の「数式だけで閉じた点列を毎回生成」から、

`tone → template 選択 → affine + tail`

の段階を挟む形に寄せる。

### 具体

1. **トーンごとに原型を数種類**
   - 雲: 3〜5 種
   - ギザギザ: 4〜6 種（いずれも「控えめトゲ」系統）
2. **セリフの tone と文字量**から近い原型を選択
3. **顔位置・空き領域**に合わせて
   - スケール
   - アスペクト比
   - しっぽの角度・長さ（必要な tone のみ）
   を変形
4. ギザギザは加えて **トゲ密度・トゲ長のばらつき**を薄いパラメータで触れると寄せやすい

### 原型の中身（実装の現実解）

著作権を踏まえ、当面は次のどちらか（または併用）:

| 種類 | 内容 |
|------|------|
| **手描き／自作 SVG・ポリゴン原型** | 理想に近いシルエットを数個リポジトリ同梱（推奨） |
| **純パラメータだが「原型プリセット」** | 爆発マークにならない係数セットを名前付きで持つ（素材ゼロのフォールバック） |

「本物の漫画から切り取り」は学習・研究用途でも配布リスクがあるため、**同梱素材は自作または権利クリアなものに限る**。

## 4. トーン別の形の目標

| tone | 形の目標 | 尻尾 |
|------|----------|------|
| normal | なめらか楕円〜やや角丸 | 短い三角（#4） |
| shout | 角張った楕円＋**適度な**トゲ。爆発マーク禁止 | **基本なし**（#3） |
| thought | コンパクトな雲（複数円のやわらかい輪郭） | 丸の連なり |
| whisper | 楕円＋破線 | 短い三角 |
| narration | 矩形 | なし |

## 5. 実装タスクへの落とし込み

| 段階 | 内容 | Issue |
|------|------|--------|
| すぐ | shout: tail オフ、トゲ数・振幅を下げて「控えめギザ」プリセット | #3 |
| すぐ | thought: sin 蜘蛛をやめ、複数円クラウド or 原型1種 | #14 |
| 次 | `shapes/templates/` に SVG/JSON 点列原型、選択＋affine | #3 #14 拡張 or 新規 |
| 次 | 文字量で template index / scale | #1 と連携 |
| 後 | トゲ密度などの微パラメータ、中間トーン | Wave 5 付近 |

新規 Issue を切る場合のタイトル案:

- `描画: shape template 選択 + affine 変形パイプライン（ハイブリッド）`
