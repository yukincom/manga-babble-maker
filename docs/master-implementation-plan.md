## アーキテクチャ（固定）

```text
[任意] 小説シナリオ
        │  エージェント / LLM（core 外）
        ▼
台本テキスト (script-format.md)
        │  parse_script（決定的）
        ▼
lines.json  +  detections.json
        │  place（スロット＋文字量サイズ）
        ▼
layout.json  (text / tone / shape / bbox が正)
        │  render
        ▼
bubble.png（枠） text.png（プレビュー） manifest.json
```

- **編集の正** = JSON / 台本。PNG 文字はプレビューのみ  
- **tone** ≠ **shape**
