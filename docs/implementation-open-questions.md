## 3. あると助かる資料

リポジトリに置けるものは `samples/` または `docs/references/` へ。置けない場合は Issue にパスや説明だけ。

| 優先 | 資料 | 用途 |
|------|------|------|
| 高 | 同じ話の**理想レイアウト画像**（吹き出し・文字入り） | 受け入れの正。#1–#5 の目視基準 |
| 高 | 現状の**悪い出力**スクショ（任意・real で可） | 改行・雲・尻尾の回帰確認 |
| 中 | 叫び吹き出しの好きな作例 1–2 枚 | #3 有機形 |
| 中 | 雲型心の声の好きな作例 | #14 |
| 中 | 使いたい日本語フォント（OFL 等で同梱可なもの） | text プレビューの安定 |
| 低 | 誌面差（少年／青年の thought）のメモ | 後の分岐 |

**こちらから勝手に取れないもの:** 他 private リポジトリ、無断の商用スキャン、未共有のクラウド上だけにあるファイル。
