方針: **見た目が早く良くなる配置・描画を先に**、文字は「読める方向」を早く、組版の細部は後。

## Wave 1 — 配置の土台（最優先）

理想稿との差の大半は「デカすぎ・遠すぎ・コマまたぎ」。ここを直すと一変する。

| 順 | Issue | なぜこの順か | 完了の目安 |
|----|-------|--------------|------------|
| 1 | **#1** サイズ＝文字量 | 巨大フキダシの元凶。他の配置調整の前提 | 短文がコマの一部に収まる |
| 2 | **#2** 話者近傍 | サイズ適正化のあとで距離ペナルティが効く | 顔の近くに来る |
| 3 | **#5** frame 内・自動割り当て | 近傍配置をコマ内に閉じる | 尻尾・枠がコマを突き抜けない土台 |

**まとめて1 PR でも可**（place モジュール中心）。  
**評価:** `python -m manga_babble run ... samples/real` の preview を理想稿と比較。

## Wave 2 — 描画・トーン

| 順 | Issue | なぜこの順か | 完了の目安 |
|----|-------|--------------|------------|
| 4 | **#7** トーン規則 | 正月セリフ等が不要に shout になるのを止める。#3 の前に判定を直すと検証が楽 | `！` 1個は normal 寄り |
| 5 | **#3** shout 尻尾オフ ＋ 有機形 | まずは **尻尾オフ**を必須。有機的スパイクは同 PR の後半 or フォロー | 叫びに槍尻尾が付かない |
| 6 | **#4** 尻尾短縮・コマ内 | normal / whisper の尻尾。#3 とコードが近いので続けて | 長い横断尻尾が消える |
| 7 | **#14** thought を雲形に | コンパクトで柔らかい雲。大きすぎ・蜘蛛型をやめる | 心の声が一目で雲 |
| 8 | **#16** template + affine | 原型選択＋変形のハイブリッド本丸（docs/bubble-shape-approach.md） | tone 後に template→変形→tail |

**#3 / #14 / #16 の切り方**

- #3: shout は tail なし ＋ トゲ控えめプリセット（すぐ効く）
- #14: thought を雲に見えるようにする（すぐ効く）
- #16: 複数原型・選択・affine のパイプライン（形の本丸）

形状の比較（素材 vs パラメータ vs ハイブリッド）は **docs/bubble-shape-approach.md**。

## Wave 3 — 文字が読める（方向 ＋ 改行）

| 順 | Issue | なぜこの順か | 完了の目安 |
|----|-------|--------------|------------|
| 8 | **#6 ＋ #10 ＋ #13** 統合 | 同じ `text_raster`。方向・改列・**単語途中で切らない**は一体 | 右列文頭・上→下、単語がバラけない |
| 9 | **#12** `lang` | 分岐の入口。ja 固定でもよいが schema に足しておく | options.lang / 推定 |

**#13 の要点（必須）**

- 欧文: スペース区切り word の途中で改行・改列しない  
- 日本語: 文字数だけでの無秩序分割をやめ、可能な範囲でまとまり単位（簡易禁則可。深い禁則は #11）

この時点で「配置はマシ・文字は読める」まで到達。実画像レビューの第2ラウンド向き。

## やらない／後回しの線引き

- 検出モデルの再学習 → 今の Issue 外（検出は実画像で既に使える）
- ベクター必須化 → 方針どおりやらない
- 完璧な縦中横・禁則 → #11 の後半、必要なら別 Issue
- 有機的叫びの芸術品質 → #3 の第二段階

---

## 推奨スタート

**次に手を付けるなら S1 = #1 → #2 → #5（または一括 PR）。**

コマンド例（実装後の回帰）:

```bash
source .venv/bin/activate
export PYTHONPATH=.
python -m manga_babble run \
  --image samples/real/page.jpg \
  --lines samples/real/lines.json \
  --detections outputs/real/detections.json \
  --out-dir outputs/real
```
